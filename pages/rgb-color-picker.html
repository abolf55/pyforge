انتخابگر رنگ RGB

دستیار هوشمند رنگ برای توسعه‌دهندگان پایتون و طراحان وب

درباره پروژه

یک ابزار وب سبک و فارسی برای انتخاب رنگ و دریافت سریع کدهای HEX و RGB. این ابزار مخصوصاً برای استفاده در رابط‌های گرافیکی Tkinter / CustomTkinter، بازی‌های Pygame و طراحی وب مدرن توسعه یافته است.

تکنولوژی‌ها: HTML5, CSS3, JavaScript نوع پروژه: ابزار وب / قابل اجرا آفلاین پیش‌نیاز: مرورگر مدرن

قابلیت‌های اصلی

  • انتخاب دقیق رنگ با ابزار اختصاصی مرورگر
  • نمایش لحظه‌ای پیش‌نمایش رنگ انتخاب‌شده
  • محاسبه و ارائه کد HEX استاندارد (مانند #36D7FF)
  • ارائه مقدار عددی RGB سازگار با پروژه‌های Python و Pygame
  • امکان کپی‌کردن مستقیم کدها در کلیپ‌بورد با یک کلیک
  • طراحی مدرن، دارک، راست‌به‌چپ (RTL) و کاملاً واکنش‌گرا
