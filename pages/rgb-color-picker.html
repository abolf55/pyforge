انتخابگر رنگ RGB

دستیار رنگ برای پروژه‌های پایتون و وب

دربارهٔ پروژه

یک ابزار وب سبک و فارسی برای انتخاب رنگ و دریافت سریع کدهای HEX و RGB. این ابزار مخصوصاً برای استفاده در رابط‌های Tkinter، بازی‌های Pygame و طراحی وب مفید است.

قابلیت‌ها

  • انتخاب رنگ با انتخابگر رنگ داخلی مرورگر
  • نمایش پیش‌نمایش لحظه‌ای از رنگ انتخاب‌شده
  • نمایش مقدار HEX مانند #36D7FF
  • نمایش مقدار RGB قابل استفاده در پروژه‌های Python
  • امکان کپی‌کردن مقدار خروجی با کلیک
  • رابط کاربری فارسی، راست‌به‌چپ و واکنش‌گرا

روش اجرا / استفاده
