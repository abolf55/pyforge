PyVault

مدیریت امن رمز عبور با رابط کاربری گرافیکی و ذخیره‌سازی محلی.

توضیحات پروژه

PyVault یک برنامه مدیریت رمز عبور است که با استفاده از پایتون و کتابخانه CustomTkinter ساخته شده است. این برنامه به شما امکان می‌دهد رمزهای عبور خود را به صورت امن ذخیره و مدیریت کنید. اطلاعات رمز عبور در یک فایل پایگاه داده SQLite به صورت رمزنگاری شده ذخیره می‌شود تا از دسترسی غیرمجاز جلوگیری شود.

ویژگی‌ها:

  • ایجاد، ویرایش و حذف رمزهای عبور.
  • قابلیت جستجو در بین رمزهای عبور ذخیره شده.
  • رمزنگاری پایگاه داده برای امنیت بیشتر (با استفاده از ماژول‌های داخلی پایتون یا کتابخانه‌های جانبی).
  • رابط کاربری گرافیکی دوستانه با استفاده از CustomTkinter.
  • قابلیت تبدیل به فایل اجرایی با PyInstaller.

فناوری‌ها:

Python CustomTkinter SQLite PyInstaller
