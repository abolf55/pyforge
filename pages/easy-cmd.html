Easy CMD

ابزار چندکارهٔ خط فرمان برای ویندوز

دربارهٔ پروژه

Easy CMD مجموعه‌ای از ابزارهای پرکاربرد را در یک منوی سادهٔ خط فرمان جمع می‌کند. این پروژه برای انجام کارهای سیستم، شبکه و مدیریت محیط پایتون طراحی شده است.

قابلیت‌ها

  • نمایش IP سیستم با ipconfig و بررسی IP وب‌سایت‌ها با nslookup
  • نمایش اطلاعات دستگاه با systeminfo
  • نمایش و نصب پکیج‌های پایتون با pip
  • دریافت اطلاعات عمومی یک IP مانند کشور، شهر، ISP و منطقه زمانی
  • تبدیل اسکریپت Python به EXE با PyInstaller و انتخاب onefile یا onedir
  • پشتیبانی از آیکون، نام خروجی، فایل جانبی و پاک‌سازی فایل‌های موقت
  • تبدیل دسته‌جمعی فرمت عکس‌ها و تغییر اختیاری ابعاد آن‌ها

روش اجرا / استفاده

Windows + Python 3.10 یا جدیدتر. برای بخش‌های IP و تصویر، کتابخانه‌های requests و Pillow باید نصب باشند.
