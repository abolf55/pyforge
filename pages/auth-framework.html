User Authentication Framework

یک چارچوب امن، سبک و ماژولار برای ثبت‌نام، ورود و مدیریت سطوح دسترسی کاربران با رابط کاربری اختصاصی CustomTkinter و پایگاه داده SQLite.

درباره پروژه

این پروژه یک فریم‌ورک آماده برای احراز هویت کاربران در برنامه‌های دسکتاپ پایتون است. با استفاده از این سیستم می‌توانید بخش ثبت‌نام و ورود برنامه خود را بدون نیاز به کدنویسی مجدد، به پایگاه داده متصل کرده و داده‌های کاربران را مدیریت کنید.

زبان توسعه: Python رابط کاربری: Tkinter / CustomTkinter پایگاه داده: SQLite 3 نسخه: پایدار ۱.۰.۰

ویژگی‌های کلیدی

  • احراز هویت دقیق نام کاربری و تطابق رمز عبور
  • پایگاه داده سبک محلی با SQLite3 بدون نیاز به نصب سرور خارجی
  • طراحی مدرن دسکتاپ با استفاده از فریم‌ورک CustomTkinter
  • کنترل خطاهای پیشرفته، بررسی فرمت ورودی‌ها و عدم ثبت نام کاربری تکراری
  • امکان گسترش و اتصال سریع به دیگر پروژه‌های نرم‌افزاری دسکتاپ
  • ساختار ماژولار و تفکیک شده برای توسعه راحت‌تر

بخش مدیریت و تست اولیه

سیستم دارای بخش مدیریت داخلی برای بررسی لیست کاربران و وضعیت دسترسی‌ها است. اطلاعات تست پیش‌فرض:

نام کاربری (Username): admin
رمز عبور (Password): admin123
نکته امنیتی: این مشخصات صرفاً برای تست آزمایشی است و در نسخه نهایی باید تغییر یابد.
