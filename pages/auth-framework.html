User Authentication Framework

نسخه پایدار ۱.۰.۰

یک چارچوب امن، سبک و ماژولار برای ثبت‌نام، ورود و مدیریت سطوح دسترسی کاربران با رابط کاربری اختصاصی Tkinter / CustomTkinter و پایگاه داده SQLite.

زبان توسعه
Python
رابط کاربری
CustomTkinter
پایگاه داده
SQLite 3
سطح امنیت
Local Check

📌 توضیحات پروژه

این پروژه یک فریم‌ورک آماده برای احراز هویت کاربران در برنامه‌های دسکتاپ پایتون است. با استفاده از این سیستم می‌توانید بخش ثبت‌نام و ورود برنامه خود را بدون نیاز به کدنویسی مجدد، به پایگاه داده متصل کرده و از امنیت داده‌های کاربران اطمینان حاصل کنید.

✨ ویژگی‌های کلیدی

🛡️

احراز هویت دو مرحله‌ای منطقی

بررسی نام کاربری و تطابق رمز عبور به صورت رمزنگاری شده.

🗄️

پایگاه داده محلی

استفاده از SQLite3 جهت ذخیره‌سازی بهینه مشخصات بدون نیاز به سرور خارجی.

🎨

طراحی مدرن دسکتاپ

پیاده‌سازی رابط کاربری زیبا با Tkinter و CustomTkinter.

⚠️

کنترل خطاهای پیشرفته

بررسی صحت ایمیل، طول رمز عبور و جلوگیری از ثبت‌نام‌های تکراری.

⚙️

پنل مدیریت داخلی (Admin Panel)

دسترسی سطح بالا برای مدیریت پایگاه داده کاربران

این فریم‌ورک شامل یک بخش مدیریتی مجزا است که به ادمین سیستم اجازه می‌دهد لیست تمام کاربران ثبت‌نام شده را مشاهده کند، دسترسی‌ها را تغییر دهد یا کاربری را حذف کند.

🔑 اطلاعات ورود پیش‌فرض (جهت تست)

نام کاربری (Username): admin
رمز عبور (Password): admin123
💡
توصیه امنیتی: این اطلاعات ورود صرفاً برای تست اولیه تنظیم شده است. برای استفاده واقعی، حتماً رمز عبور را تغییر داده و از هش‌سازی (مثل bcrypt) استفاده کنید.
