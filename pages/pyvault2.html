PyVault 2

نسخه پیشرفته و امن سیستم مدیریت رمز عبور با رابط کاربری گرافیکی مدرن (Tkinter/CustomTkinter) و قابلیت تولید رمزهای تصادفی.

توضیحات پروژه

PyVault 2 یک ابزار دسکتاپ برای مدیریت ایمن رمزهای عبور است. این پروژه به کاربران اجازه می‌دهد رمزهای عبور خود را به همراه جزئیات سرویس مربوطه ذخیره کرده و به راحتی آن‌ها را بازیابی یا ویرایش کنند. تمرکز اصلی بر سادگی استفاده و امنیت داده‌ها در سطح محلی است.

ویژگی‌های کلیدی پروژه

  • مدیریت رمزهای عبور: امکان ذخیره، ویرایش، حذف و مشاهده امن رمزهای عبور.
  • تولید رمز تصادفی: قابلیت ساخت رمزهای قوی با تنظیم طول و نوع کاراکترها (اعداد، حروف، نمادها).
  • پایگاه داده محلی: استفاده از SQLite3 برای ذخیره‌سازی امن و مستقل داده‌ها.
  • رابط کاربری مدرن: طراحی جذاب و کاربرپسند با استفاده از CustomTkinter.
  • کپی آسان: دکمه اختصاصی برای کپی سریع رمز عبور یا نام کاربری در کلیپ‌بورد.

پنل مدیریت داخلی

دسترسی برای مشاهده اطلاعات کاربران و داده‌های ذخیره شده

این بخش به ادمین اجازه می‌دهد لیست کاربران ثبت‌نام شده و اطلاعات مربوط به رمزهای ذخیره شده آن‌ها را مشاهده کند. این قابلیت برای اهداف تستی و بررسی عملکرد سیستم طراحی شده است.

اطلاعات ورود پیش‌فرض (جهت تست):

نام کاربری (Username): admin
رمز عبور (Password): admin123
⚠️ توصیه امنیتی: این اطلاعات ورود صرفاً برای تست اولیه در محیط محلی (Development) تنظیم شده است. رمزهای عبور کاربران در این پروژه به صورت متن ساده (Plain Text) ذخیره می‌شوند. برای استفاده در محیط‌های عملیاتی، حتماً باید از الگوریتم‌های هش‌گذاری مانند bcrypt یا hashlib برای رمزنگاری رمزهای عبور استفاده کنید.
