👤 چارچوب احراز هویت کاربر

پروژه User Authentication Framework

یک چارچوب امن و ساده برای پیاده‌سازی ثبت‌نام، ورود کاربران و مدیریت جلسات (Sessions) در برنامه‌های دسکتاپ با رابط کاربری گرافیکی.

مشخصات و قابلیت‌های چارچوب

این پروژه با استفاده از Python و کتابخانه‌های استاندارد مانند Tkinter برای رابط کاربری و SQLite برای ذخیره‌سازی داده‌ها، یک سیستم کامل احراز هویت را فراهم می‌کند.

  • ثبت‌نام کاربر (Sign Up): فرم ثبت‌نام با اعتبارسنجی ورودی‌ها (مانند طول رمز عبور، تطابق رمز عبور با تأییدیه).
  • ورود کاربر (Login): سیستم ورود امن با بررسی نام کاربری و رمز عبور در پایگاه داده.
  • مدیریت جلسات (Session Management): پیگیری وضعیت ورود کاربر و امکان خروج (Logout).
  • پنل ادمین (Admin Panel): یک بخش اختصاصی برای مدیر سیستم جهت مشاهده لیست کاربران ثبت‌نام شده.
  • امنیت داده‌ها: ذخیره‌سازی رمزهای عبور کاربران در پایگاه داده SQLite.

⚠️ دسترسی به پنل مدیریت (Admin)

در این پروژه برای دسترسی به بخش مدیریت کاربران، یک حساب کاربری پیش‌فرض تعریف شده است:

Username: admin
Password: admin123

نکته فنی: پنل مدیریت به شما اجازه می‌دهد تمامی کاربران ثبت‌نام شده را مشاهده کنید. این بخش برای تست عملکرد سیستم احراز هویت طراحی شده است.

⚠️ هشدار امنیتی: رمزهای عبور کاربران در حال حاضر به صورت متن ساده (Plain Text) در پایگاه داده ذخیره می‌شوند. برای پیاده‌سازی امن در پروژه‌های واقعی، لازم است از الگوریتم‌های هش‌گذاری مانند bcrypt استفاده کنید.
